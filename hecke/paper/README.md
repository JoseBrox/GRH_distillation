# Hecke manuscript

[Main manuscript](main.md) is the active ordinary-mathematics extension. Its first chapters give the analytic reduction and cubic benchmark; the arithmetic chapter uses the selected-twist determinant architecture subject to the exact field and datum hypotheses. The old untwisted/degree route is preserved at [the pre-reorganization revision](https://github.com/JoseBrox/GRH_distillation/blob/6b74526223ae1724fa7872c27664b6a565f15244/hecke/paper/main.md), not accumulated in the main text. The [smoothed and trace manuscript](smoothed-and-trace.md) is another attributed alternative.

The Markdown edition is current; `./build.sh` builds a TeX/PDF edition locally. No fresh Hecke PDF build is claimed.
