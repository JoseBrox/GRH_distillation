\paragraph{An optional scalar bound for the source deficit.}
Keep the hypotheses, measures and normalizers of
Theorem~\ref{shared-whittaker-scalar-envelope}. Evaluation of a seed
is a linear functional \(\operatorname{ev}_{u,g}:C_u\to\mathbb C\).
The original direct-sum column norm gives exactly
\[
 \|\operatorname{ev}_{u,g}\|
 =\mathbf1_{N_fH_{u,f}x_uK}(g_f)\|W_u(g_\infty)\|.
\]
In a finite column cell only one dual representation block is
evaluated; character and compact group transports are unitary.
For the actual isometric restriction \(J_u:C_u^0\hookrightarrow C_u\),
put \(r_u^0=\dim C_u^0\) and
\[
 w_u^0(g)=\|\operatorname{ev}_{u,g}J_u\|,\qquad
 A_u^0(y)=\sum_{\delta\in\Delta_u\backslash G(F)}w_u^0(\delta y),
 \qquad B_u^0(y)=\sum_{\delta\in\Delta_u\backslash G(F)}w_u^0(\delta y)^2.
\]
The seed identity gives \(\int_Y B_u^0=c_ur_u^0\). Absolute
convergence of the finitely many basis seeds implies \(A_u^0<\infty\)
almost everywhere.

\begin{proposition}[The cost of distinct rational returns]
\label{shared-seed-return-deficit}
Define
\[
 K_u^0=c_u^{-1}J_u^*P_u^*P_uJ_u,\qquad
 E_u^0=c_u^{-1}\int_Y\bigl((A_u^0)^2-B_u^0\bigr)\in[0,\infty].
\]
Then
\[
 \operatorname{tr}(I-K_u^0)_+\le\min\{r_u^0,E_u^0\}.
\]
Replacing \(w_u^0\) by the full evaluation norm gives a valid upper
bound for \(E_u^0\), without any condition on how \(J_u\) meets the
column blocks.
\end{proposition}

\begin{proof}
Write \(a_\delta=c_u^{-1/2}\operatorname{ev}_{u,\delta y}J_u\) as
a row functional. The exact seed and period identities are
\[
 I=\int_Y\sum_\delta a_\delta^*a_\delta,\qquad
 K_u^0=\int_Y
   \left(\sum_\delta a_\delta\right)^*
   \left(\sum_\delta a_\delta\right).
\]
If \(E_u^0\) is finite, the off-diagonal rank-one terms are
absolutely integrable in trace norm, since
\(\|a_\delta^*a_\epsilon\|_1
=\|a_\delta\|\|a_\epsilon\|\). For every orthogonal projection \(L\),
\[
 \operatorname{tr}L(I-K_u^0)
 \le\int_Y\sum_{\delta\ne\epsilon}
                 \|a_\delta\|\|a_\epsilon\|=E_u^0.
\]
Use the positive spectral projection. Positivity of \(K_u^0\)
independently gives the bound by \(r_u^0\), including infinite
\(E_u^0\). Finally, restriction decreases each evaluation norm,
so it decreases every nonnegative off-diagonal product.
\end{proof}

The constant one is sharp. A one-dimensional seed with values \(1,-1\)
at two points of measure \(1/2\) has norm one. Folding them onto one
point of measure \(1/2\) gives zero. Its source deficit and return
bound are both one. For values \(1,1\), the same return bound is one
but the source deficit is zero. Thus absolute returns can cost much
more than the actual signed sum.

For completeness, both actual restrictions can be retained in one
scalar sufficient condition. Let \(H\) be the original finite common
target, \(H_0=\operatorname{im}\Pi\), \(n=\dim H_0>0\), and
\(R_0=\sum_u r_u^0>0\). Let \(B_0,B_\perp\) be the diagonal kernels
of \(H_0,H\ominus H_0\). The actual target loss satisfies
\[
 L_t=\sum_uc_u^{-1}\|(I-\Pi)P_uJ_u\|_{\rm HS}^2
                   \le\int_YF B_\perp.
\]
Target restriction subtracts a positive operator of trace \(L_t\)
from the source Gram operator. Therefore, for the final maps
\(c_u^{-1/2}\Pi P_uJ_u\) at the prescribed scale \(c=R_0\),
\[
 g_{R_0}+b_{R_0}\le
 \frac{\displaystyle\sum_u\min\{r_u^0,E_u^0\}
       +\int_YF B_\perp
       +\int_Y(F-R_0/n)_+B_0}{R_0}.
\]
This follows from positive-trace subadditivity and the preceding
scalar-envelope theorem. The source defect is also at most one.
If the first two numerator terms are strictly less than \(R_0\),
the final family is nonzero. The needed arithmetic estimates of these
integrals remain separate; all rational returns are included, and the
signed orbital estimates remain available when sharper.
